Requisitos Não Funcionais (RNF)
RNF01

O sistema deve utilizar banco de dados SQLite.

RNF02

O sistema deve seguir a arquitetura MVC com camadas Service e Repository.

RNF03

O sistema deve possuir interface simples e de fácil utilização.

RNF04

O sistema deve garantir persistência dos dados cadastrados.

RNF05

O sistema deve apresentar mensagens de erro e confirmação ao usuário.
