Requisitos Funcionais (RF)
RF01

O sistema deve permitir o cadastro de cinemas.

RF02

O sistema deve permitir o cadastro de filmes.

RF03

O sistema deve permitir o cadastro de sessões.

RF04

O sistema deve permitir registrar o público de cada sessão.

RF05

O sistema deve permitir consultar filmes em cartaz.

RF06

O sistema deve permitir consultar horários das sessões.

RF07

O sistema deve permitir visualizar informações dos filmes.

RF08

O sistema deve permitir consultar relatórios de público por sessão, filme e cinema.
